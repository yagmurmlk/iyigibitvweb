# Fotoğraflar

Hakkımızda sayfası bu dosyaları arar:

- `huseyin.jpg` — Hüseyin Çıtak
- `melike.jpg` — Melike Yağmur

Dikey (4:5) oran, en az 800×1000 piksel önerilir. Dosya yoksa baş harfler gösterilir.

Şimdiki dosyalar "Bakü turist gibi gezdik" videosunun kapağından kırpılmış geçici görsellerdir.

`birlikte-*.jpg` dosyaları da kapaklardan kırpıldı (Bakü yürüyüşü, Bakü'de kar, Nevruz, Kızılcahamam). Daha yüksek çözünürlüklü fotoğraflarla aynı adlarla değiştirilebilir.
